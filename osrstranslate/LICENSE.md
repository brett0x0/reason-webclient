# OSRS Translate additions

`additions-pt-BR.json` and `additions-ESP.json` hold Portuguese and Spanish entries for the
OSRS Translate PT-BR plugin (`client/game/plugins/osrstranslate/`). They are project-owned
entries, contributed upstream to the dictionary repository
[walterrezende12-tech/osrs-translate-translations](https://github.com/walterrezende12-tech/osrs-translate-translations),
and are distributed here under this repository's licence (BSD-2, see `/LICENSE`). The upstream
dictionaries themselves are downloaded by the plugin at run time and are not bundled here.
